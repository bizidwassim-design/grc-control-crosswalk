How it works

From ISO 27001: every Annex A control with its closest match in each target framework and the overlay items that rely on it; search, filter by domain, show or hide columns. From a framework: pick any framework or overlay, then an identifier, to see the ISO controls behind it and what they map to elsewhere. Overlays: what each UAE or sector regime asks for, with confidence and source verification. Coverage: how much of each framework the crosswalk reaches. The data is the same CSV that generates the Excel workbook and the YAML in this repository.
